# D-07 住所・支払いフォーム: 必須欄が空のまま「保存」しても何も起きない(エラー無し・ボタンは有効のまま)

| 項目 | 内容 |
|---|---|
| 対象 | 住所を追加/編集・お支払い方法を追加/編集 / 保存ボタン |
| 対応 SC/TC | 観点「異常系 › 必須項目空で保存」「UI/UX › ボタン活性/非活性」 |
| 重大度 | 中(無反応はハングと区別できない。何が足りないか分からない) |
| 状態 | 起票 |
| 検出 | 手動(探索的テスト)/ iPhone 13・iOS 26.6.1・実機 |
| 起票日 | 2026-08-31 |

**再現手順**
1. ログイン → アカウント → お届け先住所 → 追加。
2. 氏名だけ入力し(他は空)、キーボードを畳んで「保存」をタップする。

**期待結果**: 未入力の必須欄が示されるか、保存ボタンが非活性になっている。

**実際の挙動**: 画面はそのまま。エラー文言・遷移・トーストのいずれも無い。保存ボタンは活性表示のまま。

**証拠**: ft_batch `tap "#btn_save" — ok` の直後の ft_snapshot が操作前と同一(`waitForChange` が
5 秒で timeout = 木が1バイトも変わらない)。
ソース: `feature/address/AddressEditViewModel.kt` `if (!requiredFilled) return`(通知なし)/
`PaymentEditViewModel.kt` 同型 / `AddressEditScreen.kt` `PrimaryButton` に `enabled` 指定なし。

**仕様裁定(要判断があれば)**: 未入力欄に `isError` を立てるか、必須が揃うまで保存を非活性にする。
