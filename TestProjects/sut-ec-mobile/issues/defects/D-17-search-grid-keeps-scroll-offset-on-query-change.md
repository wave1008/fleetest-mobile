# D-17 検索: 検索語を消す/変えると結果一覧の先頭行がチップ列の下に隠れる(前の結果の位置を保つ)

| 項目 | 内容 |
|---|---|
| 対象 | 検索 / 結果グリッド(LazyVerticalGrid) |
| 対応 SC/TC | 観点「検索・絞り込み」 |
| 重大度 | 中(1行目が見えないので「無い」と誤認する。上へ引き戻さないと出ない) |
| 状態 | 起票 |
| 検出 | 手動(探索的テスト)/ iPhone 13・iOS 26.6.1・実機 |
| 起票日 | 2026-08-31 |

**再現手順**
1. 検索タブで `モバイル` を検索(1件: `electronics_4` が先頭行に出る)。
2. 検索欄の「×(クリア)」をタップして全件表示にする。

**期待結果**: 全件一覧が先頭(`electronics_1` / `electronics_2`)から表示される。

**実際の挙動**: 一覧が**1行ぶんスクロールした状態**で出る。先頭行はチップ列の下に潜って下端だけ見え、
2行目(`electronics_3` / `electronics_4`)が最上段に見える。`キーボード` → クリアでも同じ
(直前に見えていた商品の行が最上段に固定される = 前の結果のキーを起点に位置を保つ挙動)。

**証拠**: ft_snapshot(クリア直後)`#product_card_electronics_1 (16,-92 175x255)` /
`#product_card_electronics_2 (199,152 175x32)`(y が負・高さが切れている)。スクショでも
先頭行のカードの下端だけが見える。

**仕様裁定(要判断があれば)**: クエリ/フィルタ変更のたびに `LazyGridState.scrollToItem(0)` する。
