# D-05 ホーム: バナー「今だけ全品送料無料」が送料規則(3,000円未満は500円)と矛盾する

| 項目 | 内容 |
|---|---|
| 対象 | ホーム / キャンペーンバナー |
| 対応 SC/TC | user-manual §5「送料について」・§13 FAQ「送料を無料にするには?」 |
| 重大度 | 中(表示と請求額が矛盾する = 利用者の誤解を招く) |
| 状態 | 起票 |
| 検出 | 手動(探索的テスト)/ iPhone 13・iOS 26.6.1・実機 |
| 起票日 | 2026-08-31 |

**再現手順**
1. ホームを開き、バナーの文言を読む(「今だけ全品送料無料 / 新生活応援キャンペーン実施中」)。
2. 絵本 `books_4`(¥1,100)を1点カートに入れ、カートを開く。

**期待結果**: バナーの主張と請求が一致する(全品無料なら送料 ¥0、規則どおりなら「無料」を謳わない)。

**実際の挙動**: カートは **送料 ¥500 / 合計 ¥1,600** と「あと¥1,900で送料無料」を表示する
(3点 ¥3,300 で無料 = 規則側は正しい)。バナーだけが偽り。

**証拠**: ホーム ft_snapshot `staticText "今だけ全品送料無料"` / カート ft_snapshot
`"送料" "¥500"`, `"あと¥1,900で送料無料"`。
ソース: `composeApp/.../feature/home/HomeScreen.kt` の `tr("今だけ全品送料無料", "Free shipping, today only")`。

**仕様裁定(要判断があれば)**: バナーの文言を規則に合わせる(例「3,000円以上で送料無料」)か、
キャンペーン中は `Totals` の送料規則も切り替える。
