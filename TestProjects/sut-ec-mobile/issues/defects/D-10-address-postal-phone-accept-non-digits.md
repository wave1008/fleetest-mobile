# D-10 住所: 郵便番号・電話番号に英字が通り、そのまま保存・注文に写る

| 項目 | 内容 |
|---|---|
| 対象 | 住所を追加/編集 / サーバ `POST /addresses` |
| 対応 SC/TC | 観点「異常系 › 非数字(郵便番号/電話/カード)」 |
| 重大度 | 中(配送に使えないデータが注文スナップショットへ固定される) |
| 状態 | 起票 |
| 検出 | 手動(探索的テスト)/ iPhone 13・iOS 26.6.1・実機 |
| 起票日 | 2026-08-31 |

**再現手順**
1. ログイン → アカウント → お届け先住所 → 追加。
2. 郵便番号 `abc`・電話番号 `abc`、他は正常値で保存する。

**期待結果**: 数字以外は弾かれる(または数字キーボードで入力できない)。

**実際の挙動**: 保存され、一覧に **「abc 東京都千代田区千代田1-1」「abc」** と表示される。
サーバ `GET /addresses` も `"postalCode":"abc","phone":"abc"`。iOS のキーボードも通常配列
(`KeyboardType.Number/Phone` は指定されているがハードウェア/外部入力・ペーストで通る)。

**証拠**: ft_snapshot(お届け先住所)`staticText "abc 東京都千代田区千代田1-1"` / `staticText "abc"`。
ソース: `AddressEditViewModel.save()` と `AccountStore.upsertAddress` に桁・文字種の検証なし。

**仕様裁定(要判断があれば)**: 郵便番号は数字7桁(ハイフン許容可)・電話は数字10〜11桁をクライアントとサーバの両方で検証する。
