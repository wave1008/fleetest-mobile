# D-02 アカウント: 画面下端の操作が下部タブバーに潜る(4.7インチ実機)

| 項目 | 内容 |
|---|---|
| 対象 | アカウント画面 / 下部タブバー(全画面共通のインセット) |
| 対応 SC/TC | なし(レイアウト不具合。TC 由来ではない) |
| 重大度 | 高(**操作が別の要素に当たる** = 利用者が意図しない画面へ飛ぶ) |
| 状態 | 起票 |
| 検出 | 自動シナリオ 7本 / **iPhone SE(第3世代)・iOS 26.5.2・375x667** |
| 起票日 | 2026-08-26 |

**再現手順**
1. iPhone SE(第3世代)など **667pt 高**の端末でアプリを開く。
2. ログイン済みの状態でアカウントタブを開く。
3. 画面下端の「ログアウト」(`#btn_logout`)をタップする。

**期待結果**: ログアウトされ、アカウント画面が未ログイン(「ログイン / 登録」)に戻る。

**実際の挙動**: `#btn_logout` が**下部タブバーの下に潜っており**、タップがタブ「カート」に当たって
カート画面へ遷移する。ログアウトは行われない。

**証拠**(実行レポート `scenario-20260826-231539-837-ログイン画面を開けること_S0010.md`):

```
✅ 7. tap "#btn_logout"(resolved to #btn_logout (button) /
      the target's centre is covered by #tab_cart, so this may have hit #tab_cart instead /
      nudged the element fully inside its container before touching it) — 3.10s
❌ 8. tap "#btn_login" — cannot resolve the locator: id=btn_login
   失敗時の木: screen: 375x667 / staticText "カート" / staticText "カートは空です"
```

同じ注記が**同一 run の7本**で出ている(ログイン画面 / ログイン失敗 / ログイン入力バリデーション
S0010・S0020・S0030 / サインアップ入力バリデーション / 言語切替・タブ遷移の前提崩れ)。

**影響範囲**: アカウント画面に限らず、**スクロール内容の下端がタブバー分インセットされていない**
可能性がある(他画面は未確認)。背の高い端末(iPhone 15 Pro・シミュレータの iPhone 17 Pro)では
余白に収まるため露見しない。

**仕様裁定(要判断)**: 実装側で下部タブバー分の safe-area インセット(またはコンテンツの
bottom padding)を入れる。テスト側の回避(タップ前にスクロール)は**利用者の実害を隠す**ため
本不具合の対処にはしない。

**追記(2026-08-31・iPhone 13 / iOS 26.6.1 / 390x844pt でも再現)**: 6.1 インチでも
「ログアウト」ボタンは **上端の数 pt だけ見えラベルは下部タブバーの下**(ft_snapshot
`button "Log out" id=btn_logout (16,686 358x43)` = 48pt が 43pt にクリップ)。
ツールの `tap "#btn_logout"` は ok を返すがログアウトされない(タブに吸われる。この端末では
「中心が #tab_* に覆われている」警告も出ない = 幾何上は重なっていない)。指で約 63pt スクロール
すれば届く。**「4.7インチ実機」限定の不具合ではない**。
