# D-18 住所フォーム: 「保存」ボタンが画面下端で切れ、スクロールしないと押せない(iPhone 13 / 844pt)

| 項目 | 内容 |
|---|---|
| 対象 | 住所を追加/編集 / 保存ボタン(フォーム全体の下部インセット) |
| 対応 SC/TC | なし(レイアウト不具合。D-02 / D-03 と同根) |
| 重大度 | 中(見た目は「押せる」のに押しても何も起きない。D-07 と重なると原因が分からない) |
| 状態 | 起票 |
| 検出 | 手動(探索的テスト)/ iPhone 13・iOS 26.6.1・実機(390x844pt) |
| 起票日 | 2026-08-31 |

**再現手順**
1. ログイン → お届け先住所 → 追加(何もスクロールしない)。
2. 最下部の「保存」を見る/タップする。

**期待結果**: ボタン全体が見え、タップで保存される。

**実際の挙動**: ボタンの**上端 10pt ほどだけ**が見え、ラベル「保存」は見えない。ここをタップしても
保存されない(サーバ `GET /addresses` に増えない)。フォームを約 57pt 上へ送ると全体が現れ押せる。
667pt 端末(D-03)では電話番号欄が、844pt 端末では保存ボタンが、それぞれ下端に潜る。

**証拠**: ft_snapshot `button "保存" id=btn_save (16,759 358x48)` の子 `staticText "保存" (181,755 28x3)`
(高さ 3pt にクリップ)/ スクショで下端に紫の帯だけ。`swipe .up` 後の `tap "#btn_save"` は保存される。

**仕様裁定(要判断があれば)**: フォームに `navigationBarsPadding()`/`imePadding()` と余白を入れ、
コンテンツ高が画面を超えたら常にスクロール可能にする(D-02・D-03 と同じ対処)。
