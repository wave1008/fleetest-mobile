# 相対セレクタ

相対セレクタは、基準となる要素からの**位置関係**で候補を指します。対象自身に id や
確実なラベルが無い画面(例: スイッチ自体には id が無いが、隣にテキストラベルがある)で使います。

## 基本形: 基準が先

```swift
tap("通知:rightSwitch")
```

素朴な方向の説明とは違い、**基準を先に**書き、コロンの後に方向(`right` / `left` / `above` /
`below`)と任意の型接尾辞(`Button` / `Image` / `Input` / `Label` / `Switch` / `Widget`)を
続けます。これは「`通知` から `right` 方向へ伸ばした帯に入る、最も近い `.switch`」と解決されます。
**該当する候補が無ければ失敗します** —— 「とにかく一番近いものを返す」動作にはなりません。
それをすると、レイアウトが変わったときに黙って別の要素を掴んでしまうためです。

型接尾辞を省略する(`通知:right`)と既定は `.widget`(役割が確定した要素すべて)になります。
これは容器のようなレイアウトノードを誤って掴まないためです。

## 序数

```swift
tap("数量:right(2)")
```

その方向で近い順の2番目の候補を選びます(1 オリジン、既定は1番目)。

## 任意のフィルタ

```swift
tap("#a:below(.button&&項目)")
```

型接尾辞の代わりに、方向へ任意のセレクタ式をフィルタとして渡せます。フィルタ内の `||` は
まず一致する全候補の和集合を取り、そのうえで最も近い1つを選びます —— `:right(.button||.switch)`
は「ボタンかスイッチのうち、最も近い方」という意味です。

## 連鎖

```swift
tap("見出し:right:belowButton")
```

各ステップの結果が、次のステップの基準になります。

## 基準を `<...>` で囲む

```swift
tap("<変更&&.button>:right(数量)")
```

Shirates の正典形は基準を山括弧で囲みます。これは構文糖(パース結果は囲まない形と同一)ですが、
複数語からなる基準の範囲を目で追いやすくします。

## スコープ

```swift
tap("#row >> 数量:rightButton")
```

相対セレクタの前にスコープ(`>>`)を置けます。基準・候補の両方が、スコープした容器の中だけに
絞られます。

## 実装していない記法

Shirates(Classic)の相対セレクタ語彙と比べると:

- **`:inner*`** —— 代わりに祖先 `>>` 子孫のスコープで代替します。
- **`:next*` / `:pre*`**(ツリー順で隣を指す)と**`:parent`**(子から親を指す)は
  **実装していません**。単一列のレイアウトなら `:right`/`:below` 等で「次の項目」を近似できますが、
  折り返しやグリッド配置では別の行を掴むことがあります。
- **`:flow` / `:vflow`**(フローベースのグループ化)も**実装していません** —— 根拠のある既定値を
  持てない、行のグループ分けの閾値を要求するためです。

各項目の詳しい比較と現状は[docs/shirates-parity.md](../../shirates-parity.md)を参照してください。
