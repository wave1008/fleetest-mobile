# screenshot

現在の画面を撮り、レポートに埋め込みます。

## 関数

| 関数 | 説明 |
|---|---|
| `screenshot(filename:?)` | 現在の画面を撮り、このステップ直後にレポートへ埋め込みます。ファイル名省略時はステップ連番の名前になります。ラベル無しの位置引数でも書けます(`screenshot("a.png")`)。 |

## 例

```swift
tap("#login_btn")
screenshot()               // ステップ連番のファイル名
screenshot("after_login.png")
```

## 注意点

- スクリーンショットは撮ったステップの直後にレポートへ埋め込まれるので、見たい位置に
  合わせて呼び出しを置いてください。
- Android では、**WebView 画面が端末のキャプチャに写らないことがあります**(端末側のキャプチャ
  層が WebView の層を落とすことがあるため)。これが起きると、空白の帯を検出して別経路
  (CDP)で撮ったページ画像を自動で合成しますが、これはアプリで WebView のデバッグが有効な
  ときだけ働きます(通常は debug ビルドのみ)。写らないのは間欠的なので、画面の到達確認は
  スクリーンショットではなく木のアサーション(`exist` / `notExist`)で行ってください。
