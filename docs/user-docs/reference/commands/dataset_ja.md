# テストデータ・アカウント(account, data)

ログイン用のアカウントやテストデータを、シナリオのソースに直書きせず JSON ファイルから引きます。
名前・引数・キーの書式は Shirates と同じです。

## 関数

| 関数 | 説明 |
|---|---|
| `account("[account1].password") -> String` | アカウントのデータセット(`accounts.json`)の値を返します。 |
| `account("[account1]", "password") -> String` | 上と同じ(データセット名と属性名を分けて渡す形)。 |
| `data("[order1].item") -> String` / `data("[order1]", "item") -> String` | テストデータ(`data.json`)の値を返します。置き場・上書きは `account` と同じです。 |

キーは `[データセット名].属性名` で、**最後の `.` で分けます**(`[a.b].x` はデータセット `[a.b]` の属性 `x`)。
値は他のコマンドの引数にそのまま渡せます。

```swift
action {
    select("#login_id").type(account("[account1].id"))
    select("#login_password").type(account("[account1].password"))
}
```

成功してもステップは記録しません(値を返すだけの関数です)。

## ファイルの置き場と上書き

ファイルは Shirates のデータセット JSON と同じ形です(属性の値は文字列だけ。数値や真偽値の属性を持つデータセットは拒否します)。

```json
{
  "[account1]": { "id": "alice@example.com", "password": "..." },
  "[account2]": { "id": "bob@example.com",   "password": "..." }
}
```

| 場所 | 用途 |
|---|---|
| `<プロジェクト>/dataset/accounts.json`・`data.json` | プロジェクトに置く共有の値(リポジトリに入れてよい値) |
| `~/.config/fleetest/dataset/<プロジェクト名>/accounts.json`・`data.json` | **この Mac だけの値**(パスワードなど、リポジトリに入れない値)。プロジェクト名はプロジェクトのフォルダ名 |

- マシン側のファイルは、プロジェクト側の値を**属性単位で上書き**します。上書きされない属性はプロジェクト側のままで、
  マシン側にだけある属性・データセットも使えます。
- どちらのファイルも無くても構いません(使わなければ何も起きません)。**片方が壊れている(JSON として読めない)ときは、
  もう片方に値があっても失敗にします**(壊れたファイルを飛ばして古い値で動かないため)。
- 別の Mac で実行するときは、その Mac のマシン側のファイルが使われます。
- ファイルはシナリオの実行ごとに(初めて呼んだときに)1回だけ読みます。

## 値が無いとき

ファイルが無い・データセットが無い・属性が無い・JSON が壊れている・キーに `.` が無い、のどれでも、そのステップを失敗にして
シナリオを中断します。失敗文には、見たファイルのパスを全部と、何が無かったかが出ます(値は出しません)。

## dry-run

dry-run と一覧の取得ではファイルを読まず、**キーの文字列をそのまま返します**(Shirates の no-load 実行と同じ)。

## ファイルをそのまま使う(`dataFile`)

キーと値で表せないデータ(多数の行の CSV・API に送る本文の JSON・画像など)は、データセットのフォルダに
ファイルとして置き、`dataFile("ファイル名")` で場所(`URL`)を受け取ります。読み方は Swift の普通の書き方です。

```swift
let rows = (try? String(contentsOf: dataFile("csv/users.csv"), encoding: .utf8)) ?? ""
for line in rows.split(separator: "\n").dropFirst() {   // 1行目は見出し
    // …
}

let body = (try? String(contentsOf: dataFile("api/new_order.json"), encoding: .utf8)) ?? ""
httpRequest("https://api.example.com/orders", method: "POST", body: body)
```

- 探す場所は `account()` / `data()` と同じ2つです。シナリオを実行する Mac の
  `~/.config/fleetest/dataset/<プロジェクト名>/<ファイル名>` があればそれを、無ければ
  `TestProjects/<プロジェクト名>/dataset/<ファイル名>` を使います。
- **差し替えはファイル単位です**(`accounts.json` のような属性単位の上書きはしません。中身を混ぜません)。
- ファイル名はデータセットのフォルダからの相対パスで書きます(`csv/users.csv` のようにフォルダを挟めます)。
  `/` や `~` で始まる名前と `..` を含む名前は使えません。
- どちらにも無いときは、そのステップを失敗にしてシナリオを中断します(探した2つのパスを表示します)。
  このとき返る `URL` は空のファイルを指すので、続けて書いた読み込みは空の文字列を読むだけで、シナリオの
  プロセスは落ちません。
- 見つかったときはステップを記録しません。dry-run では、見つからなくても失敗にしません(空のファイルを返します)。

## 秘密の伏せ字化

**既定では伏せません。** `type(account("[account1].password"))` と書くと、ステップの説明・実行ログ・レポートに
パスワードがそのまま残ります。

シナリオを実行する Mac の `~/.config/fleetest/config.json` に `redactAccountValues` を書くと、その Mac で実行するシナリオでは
**`account()` で返した値を、レポート・実行ログ・結果 JSON で `***` に置き換えます**(`data()` は伏せません)。
設定はシナリオを実行する Mac のものが使われます(別の Mac で実行するときは、その Mac に書きます)。

```json
{
  "redactAccountValues": true
}
```

伏せるときの扱いは次のとおりです。

- 伏せるのは、呼んだデータセットの**全属性**の値です(`id` も伏せます)。
- **4 文字未満の値は伏せません**(`ab` のような短い値は、無関係な文字列まで `***` に変えてしまうため)。
- 伏せられるのはシナリオが書き出す文字列(ステップの説明・失敗の理由・実行ログ・Markdown レポートと失敗時の要素一覧)です。
  **スクリーンショット(画素の中の文字)は伏せられません**。パスワード欄が平文で表示される画面の失敗時のスクリーンショットには、
  値が写ります。
- `account()` の値を `writeMemo` に書くと、他のシナリオへ渡るメモの値も `***` になります(メモに秘密を入れないでください)。
- 値が他の文字列の一部に偶然一致すると、そこも `***` になります(4 文字以上の短いパスワード `true` が JSON の `true` を
  壊す、など)。
