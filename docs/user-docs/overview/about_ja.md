# Fleetest とは

[in English](about.md)

Fleetest は モバイルアプリの E2E テストツールです。Claude Code などの
AIアシスタントから利用することを前提に設計されています。

## 名前に込めた3つの特徴

- **fleet**
  - Simulator・Emulator・実機などのデバイスの集合を意味する **fleet(フリート)** を使って並列にテストします。
- **fleetest**
  - 英単語の **fleet** (すばやい)の最上級が **fleetest** です。デバイス単体および並列実行時に高速に動作するようチューニングが施されています。
- **free**
  - OSSなので無料で入手できます。また、手元のMacで完全ローカルで動作し、テスト実行時に課金は発生しません。(AIアシスタントの利用料は除く)

## AI がテストコードを作る

テストを作るのは AIアシスタントです。成果物はテストコードです。

AIアシスタントに指示するとCLI や MCP 経由でアプリを操作して必要な情報が収集され、専用のDSLを使ったテストコードが作成されます。

## テストコードが決定的にテストを実行する

テストを実行するのはテストコードです。

テストは確率的ではなく決定的に実行することが可能です。
テスト結果がぶれにくく、高速で、課金が発生しません。

## カスタムドライバーによる最適化

iOS, Androidとも独自のカスタムドライバーを実装して最適化を行なっています。既存の汎用ドライバーに依存せず、独自の改良が可能となっています。

## iOS Simulator用ハイブリッドエンジン

iOS Simulator向けにデザインされたハイブリッドエンジンは fleetest の特徴的な仕組みの一つです。高速な in-app エンジンと 汎用的な XCUITest エンジン を自動的に使い分けます。

- **in-app エンジン**
  - テスト対象アプリの起動時にアプリのプロセスへ注入されます。プロセスをまたぐ往復が無いので高速に動作します。
- **XCUITest エンジン**
  - テスト対象アプリ以外の操作はこちらで行います。in-app で実行できない操作はこちらへ回します。

| 操作例 | 利用するエンジン |
|---|---|
| 画面の読み取り・文字入力・タップ | in-app |
| OS のシステムアラートの読み取り・タップ | XCUITest |
| ホーム画面・アプリスイッチャー・別のアプリ | XCUITest |

## アプリの改変は不要

- アプリへライブラリを組み込んだり、テスト専用のビルドを作ったりする必要はありません。普段使っているデバッグ用アプリのファイルがそのまま使えます。

## アクション実施後の自動整定
- アクション実施後の整定(画面遷移が落ち着くのを待つこと)はドライバー内で自動で行われます。ユーザーがsleepの秒数を調整するような場当たり的な同期方式よりもテストのフレークが抑制されます。

## 完全ローカル実行
- Macを使用して完全にローカルでテストを実行することが可能です。**テストの実行時は**、アプリや画面の情報が Mac の外に出ません。テストを作るときは、使う AIアシスタントに画面の内容が送られます。ローカル LLM を使えば、作るときも含めて完全にローカルにできます。クラウドサービスの利用が制限されているような高いセキュリティが求められる案件で利用しやすいです。
