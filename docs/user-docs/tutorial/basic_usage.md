# Basics of using fleetest

[in Japanese(日本語)](basic_usage_ja.md)

fleetest is used by **asking an AI assistant such as Claude Code in natural language**.

For example, you can do things like the following.

- Installation
- Creating configuration files
- Adding devices
- Creating test scenarios
- Running tests
- Analyzing test results
- Investigating the cause of errors and fixing test scenarios
- Troubleshooting

You can also use other AI assistants: [AI assistants other than Claude Code](../reference/tools/other_agents.md)
