# VSCode で見る

[in English](watching_in_vscode.md)

AIアシスタントがテストを作り、実行している間、何が起きているかは VSCode 拡張で**見る**ことができます。
VSCode 拡張は[クイックスタート](../quick-start_ja.md)のインストールで入ります。
このページでは、手順を追って、拡張の画面で見えるものを確かめます。

## 1. デバイスモニターを開く

コマンドパレットで「fleetest: デバイスモニターを表示」を実行するか、VSCode 左下のステータスバーの
**fleetest mobile** をクリックします。

見えるもの:

- 「デバイスモニター」タブが開き、上から **ラインビュー**(デバイスのタイルの並び)・**グリッドビュー**
  (選択したデバイスの拡大表示)・**実行ログビュー**(選択したデバイスの実行ログ)の3つのペインが並びます。
- ラインビューには、デバイスの画面がほぼリアルタイムに並びます。AIアシスタントが探索している様子や、テストが
  複数のデバイスで並列に走っている様子をそのまま見られます。
- 上部の「実行中」欄には、いま走っている実行が「何本中何本」「残り何分」つきで出ます。

<img src="../images/tutorial/ja/vscode_device_monitor.png" width="720" alt="デバイスモニター">

## 2. タイルを選んで拡大表示と実行ログを見る

ラインビューのタイルをクリックして、デバイスを選びます。AIアシスタントにテストの実行を指示している間に試すと、
動きが分かりやすくなります。

```text
作成したシナリオを iOS で実行して。
```

見えるもの:

- 選んだデバイスの画面が、グリッドビューに拡大して出ます。
- 実行ログビューに、そのデバイスの実行ログ(どの手順を実行中か・成否)が流れます。
- グリッドビューと実行ログビューに出るのは、ラインビューで選択したデバイスだけです。何も選んでいないと、
  どちらにも「デバイスを選択して下さい」と出ます。
- ちょうど1台だけ選ぶと、グリッドビューの中に拡大表示と実行ログが横に並び、下の実行ログビューは同じログが
  二重にならないよう自動で畳まれます。

## 3. 自分の手で触る(ライブ操作)

「ライブ操作」タブを開きます(コマンドパレットの「fleetest: ライブ操作を表示」でも開けます)。
デバイスの画面をマウスで直接操作できます(クリックでタップ・ドラッグでスワイプ)。
AIアシスタントへ指示する前に画面の様子を確かめたいとき、テストの前提になる状態を手で作りたいときに使えます。

見えるもの:

- クリックした位置がデバイスの画面でタップされ、画面が更新されます。

「レコーディング開始」→ 操作 →「レコーディング終了」で、操作をそのままシナリオにすることもできます。
録画で作ったシナリオには検証が入らないので、仕上げは AIアシスタントへ指示します
([テストを作る](creating_tests_ja.md#録画して作るvscode))。

<img src="../images/tutorial/ja/vscode_live_control.png" width="720" alt="ライブ操作">

## 4. Test Explorer から実行する

VSCode の Testing ビューを開きます。プロジェクトのシナリオがフォルダ → クラス → テストの3階層で並びます。

1. コマンドパレットで `fleetest: 実行プロファイルを選択` を実行し、使う実行プロファイルを選びます
   (選んでいないと、実行は始まらずにエラーになります)。
2. テストを選び、「実行」または「実行 (dry-run)」を押します。

見えるもの:

- 成否がその場で表示されます。失敗したテストからは、レポートを開けます。
- 実行中のデバイスは、手順 1〜2 のデバイスモニターで見られます。

<img src="../images/tutorial/ja/vscode_test_explorer.png" width="720" alt="Test Explorer">

## 5. 録画を見る

「テストセッション」タブを開きます。録画は既定で有効です。デバイスモニターを表示したまま実行が終わると、
自動でこのタブに切り替わります。

見えるもの:

- シナリオごとの動画と手順を見返せます。
- 結果を Excel ファイルに書き出すこともできます。

容量を抑えたいときは、失敗したシナリオの録画だけを残せます。

### AIへの指示文

```text
fleetest の iOS の実行で、失敗したシナリオの録画だけ残すようにして。
```

<img src="../images/tutorial/ja/vscode_test_sessions.png" width="720" alt="テストセッション">

## 6. 結果ダッシュボードを見る

コマンドパレットで「fleetest: 結果ダッシュボードを開く」を実行します。

見えるもの:

- 実行の履歴・新たに落ちたテスト・回復したテスト・成功率の一覧。

<img src="../images/tutorial/ja/vscode_results_dashboard.png" width="720" alt="結果ダッシュボード">

## Mac が重いとき

画面の配信は Mac の負荷になります。たくさんのデバイスを並列に動かしていて重いときは、
デバイスモニターの「ライブ更新」を OFF にすると配信が止まり、負荷が下がります(状態の表示は続きます)。
