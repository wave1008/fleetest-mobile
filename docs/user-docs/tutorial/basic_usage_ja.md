# fleetest の使い方の基本

[in English](basic_usage.md)

fleetest は、Claude Code などの AIアシスタントへ**自然言語で指示して**使います。

例えば以下のようなことを実行できます。

- インストール
- 設定ファイルの作成
- デバイスの追加
- テストシナリオの作成
- テストの実行
- テスト結果の分析
- エラーの原因調査とテストシナリオの修正
- トラブルシューティング

Claude Code 以外の AIアシスタントでも使えます: [Claude Code 以外の AIアシスタント](../reference/tools/other_agents_ja.md)
